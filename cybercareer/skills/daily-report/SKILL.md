# Skill: Daily report

## Objective
Summarize the job search so the candidate can act quickly.

## Include
- Search date and sources checked.
- New strong matches.
- New possible matches.
- Previously seen roles with meaningful changes.
- Roles excluded and the reason.
- Resume/application drafts prepared.
- Questions requiring candidate input.
- Source failures or incomplete searches.

Be transparent about unavailable sources, blocked access, and unverified posting status.
