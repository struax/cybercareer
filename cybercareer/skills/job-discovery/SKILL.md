# Skill: Job discovery

## Objective
Find current, relevant openings using configured, permitted sources.

## Procedure
1. Read the local search configuration.
2. Search role titles and close equivalents, including employer career pages.
3. Apply location, work-arrangement, employment-type, and recency filters.
4. Capture a direct job URL and requisition ID when available.
5. Deduplicate results.
6. Verify that each posting is still active before reporting it.
7. Record unknown fields as unknown; do not guess.

## Required fields
- Employer
- Job title
- Location
- Remote/hybrid/onsite status
- Posting date or date checked
- Salary range, if disclosed
- Direct job URL
- Requisition ID, if available
- Short description of role focus

## Quality checks
- Do not confuse an employer's general careers page with the actual job posting.
- Do not report expired or duplicate listings as new.
- Follow source terms and access controls.
