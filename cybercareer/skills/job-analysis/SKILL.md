# Skill: Job fit analysis

## Objective
Compare each job description with confirmed candidate evidence.

## Method
1. Extract required and preferred qualifications.
2. Map each qualification to a specific resume/profile fact.
3. Label each item `supported`, `partial`, `gap`, or `unknown`.
4. Identify likely screening risks such as required clearance, location, travel, or certifications.
5. Explain the match score in plain language; do not imply mathematical precision.
6. Recommend apply / consider / skip, with reasons.

## Output
Include strongest matches, gaps to verify, and questions for the candidate. A missing keyword is not proof the candidate lacks the skill.
