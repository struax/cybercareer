# Skill: Resume tailoring

## Objective
Create a job-specific resume draft without changing the truth of the candidate's experience.

## Rules
- Use the source resume as the source of truth.
- Preserve employers, titles, dates, and chronology.
- Use only existing or candidate-confirmed metrics.
- Reorder and clarify relevant content; do not manufacture accomplishments.
- Align terminology with the posting only when it accurately describes the candidate's work.
- Flag unsupported requirements instead of implying experience.
- Provide a brief change log and verification questions.

## Deliverables
1. Tailored resume draft.
2. Change summary.
3. Unsupported or ambiguous claims requiring candidate review.
