# Setup checklist

- [ ] Extract the ZIP.
- [ ] Review `README.md` and `SECURITY.md`.
- [ ] Copy the example YAML to `config/job-search.local.yaml`.
- [ ] Add confirmed candidate preferences and facts locally.
- [ ] Keep resumes and personal documents out of Git.
- [ ] Select permitted job sources and configure access securely.
- [ ] Test a one-time search before scheduling recurring runs.
- [ ] Verify the report includes source dates and direct job links.
- [ ] Confirm the workflow never submits applications automatically.
