# Operating workflow

## Initial setup
- Create a private local candidate profile from verified source documents.
- Record job preferences in `config/job-search.local.yaml`.
- Confirm resume length, style, and approved metrics.
- Choose permitted job sources and configure any required access.

## Daily run
1. Search and collect openings.
2. Verify active status and direct URLs.
3. Deduplicate against the local tracker.
4. Score fit and explain evidence.
5. Prepare drafts only for suitable roles.
6. Run a truthfulness and privacy review.
7. Generate the daily report.
8. Ask the candidate about unresolved facts.

## Weekly review
- Review search terms and false positives.
- Check that sources remain accessible and permitted.
- Review application outcomes and update preferences.
- Remove stale local copies when no longer needed.
